# Mahatma Gandhi Government English Medium School

School portal for MGGEMS Lalchandpura, Jaipur.

## Setup

1. Add environment variables in Vercel:
   - `GOOGLE_CLIENT_ID`
   - `GOOGLE_CLIENT_SECRET`
   - `NEXTAUTH_SECRET`

2. Deploy automatically on push to main.

## Local

```bash
npm install
npm run dev
```
