# Mahatma Gandhi Government English Medium School

School portal for **MGGEMS Lalchandpura, Jaipur**.

**Live:** https://school-website-peach-zeta-psi.vercel.app

## Environment Variables (Vercel)

- `GOOGLE_CLIENT_ID`
- `GOOGLE_CLIENT_SECRET`
- `NEXTAUTH_SECRET`

## Local Development

```bash
npm install
npm run dev
```
